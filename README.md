# e-plantShopping

## Paradise Nursery Shopping Application

This project is a React and Redux-based shopping cart application for an online plant nursery called Paradise Nursery.

The application allows users to:

- View different house plants
- Browse plants by category
- Add plants to cart
- Increase or decrease plant quantity
- Remove items from cart
- View total cart cost
- Continue shopping
- Navigate between pages using React Router

## Technologies Used

- React
- Redux Toolkit
- React Router
- CSS
- JavaScript

## Features

- Landing Page
- Product Listing Page
- Shopping Cart Page
- Dynamic Cart Updates
- Responsive Navigation Bar
